About BusTimer

BusTimer is a lightweight, installable web app that helps you keep an eye on departures from your favorite stops.

How it works

Search for a stop, choose the vehicle type and line, and save it. Live predictions are displayed when provided by the data source; otherwise times are scheduled estimates.

Current coverage

Germany and Spain: Transitous timetable and realtime where supplied; Spain beta coverage varies. VBB remains optional for Berlin-Brandenburg. Málaga: EMT published timetables, no live predictions.

Limitations

Transitous data sources · © OpenStreetMap contributors

An internet connection is required for current departures. Predictions depend on external providers. Updates run only while the app is open, and background refresh is not guaranteed.

Data sources, licenses & contact

Málaga: GTFS EMT Málaga / Ayuntamiento de Málaga (CC BY-SA 4.0). Nationwide data: Transitous sources and attribution. Regional services: VBB transport.rest and DB transport.rest. Maps and geographic data may contain © OpenStreetMap contributors. Check source-specific licenses before redistributing timetable data.

Contact / support: BusTimer GitHub Issues. Open-source, non-commercial project; provider APIs may log your IP and queried stops. No credentials are embedded in this web app.
